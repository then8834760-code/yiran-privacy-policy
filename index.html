1. 本政策适用范围

以然收藏页是一款用于 Microsoft Edge 新标签页的浏览器扩展，主要提供书签展示与管理、新标签页搜索入口、个性化布局和壁纸，以及天气、日历、计算器、汇率、AI 网站导航、邮箱快捷入口和网页截图等辅助功能。

本政策说明扩展在运行过程中如何访问、使用、保存及向第三方服务发送相关信息。请在安装或使用扩展前阅读本政策。

2. 我们访问和处理的信息

2.1 书签信息

扩展通过 Edge 提供的书签接口读取书签名称、网址、文件夹层级等信息，以便在新标签页展示和管理书签。用户主动执行移动、删除、导入等操作时，扩展会按该操作处理相应书签。

书签内容用于扩展的书签功能，并在用户设备本地处理。当前版本不会将书签列表发送给开发者，也不会将书签内容用于广告画像或出售。

2.2 本地设置和使用偏好

扩展可能在设备本地保存以下信息：布局和界面设置、搜索引擎选择、主题与壁纸偏好、置顶书签标识、书签点击统计、天气及日历缓存、AI 分类和更新时间、图标缓存，以及用户自行填写的 AI 数据更新源地址等。

这些信息主要通过浏览器扩展本地存储、IndexedDB 和页面本地存储保存，用于记住设置、展示缓存和提供相应功能。用户上传的壁纸文件保存在本地设备中。

2.3 位置和天气信息

当用户允许浏览器提供地理位置时，扩展可读取设备提供的地理坐标，并将坐标发送给 Open-Meteo，以获取天气信息。

如果没有可用的设备定位权限，扩展可能使用 ipwho.is、GeoJS 或 ipapi.co 等 IP 定位服务，根据网络 IP 推断大致地区，再使用相应地区坐标请求 Open-Meteo 天气数据。

天气结果和相关缓存保存在本地。位置功能可能涉及设备坐标或由第三方服务根据 IP 推断的大致地区。用户可以拒绝浏览器定位权限，或关闭天气相关功能。

2.4 当前打开的标签页信息和网页截图

当用户使用网页截图功能时，扩展会读取当前浏览器窗口中打开的标签页标题和网址，以便用户选择要截图的页面。用户选择具体标签页和网站后，扩展才会申请所需的网站访问权限并执行截图操作。

截图在本地生成并下载。当前版本不会将截图上传给开发者。标签页标题和网址用于截图页面选择及相关功能，不用于建立用户的跨站浏览档案。

2.5 网站图标及网页信息

为显示书签图标，扩展可能从网站自身提供的图标地址，或 favicon.im、icon.horse 等图标服务获取图标。

如果用户启用了自动图标缓存，扩展可能读取当前打开标签页的网址，并请求相应网页以查找图标链接。此过程可能使相关网站或图标服务获知请求的 IP 地址、请求时间及被请求的网站域名。网页内容仅用于查找图标，不会因此上传给开发者。

2.6 用户主动使用的其他工具

扩展可能连接以下第三方服务，以提供对应的用户可见功能：

  • Open-Meteo 及地理编码服务：天气数据及地点信息。
  • ipwho.is、GeoJS、ipapi.co：在无法使用设备定位时，根据 IP 推断大致地区。
  • Nager.Date：国家及法定节假日数据。
  • Bing：每日壁纸相关数据和图片。
  • open.er-api.com：汇率数据。
  • api.vvhan.com：热点标题等公开信息。
  • OpenRouter：用户打开 AI 工具面板或主动刷新时，获取公开 AI 模型目录信息；此功能不发送用户的聊天内容或书签列表。
  • favicon.im、icon.horse：网站图标获取。

用户还可以主动打开搜索引擎、邮箱、AI 网站或其他快捷入口。这些网站会按照各自的隐私政策处理用户访问时产生的信息。

如果用户自行填写并启用自定义 HTTPS JSON 更新源，扩展会向该地址发出请求。该地址的运营者可能获得请求 IP 地址、请求时间等网络信息。请仅填写自己信任的地址。

第三方服务可能根据其自身政策和技术机制处理 IP 地址、请求时间、设备或网络元数据。第三方服务并非由本扩展开发者运营，其数据处理行为受各自政策约束。

3. 信息是否会发送给开发者或第三方

开发者不运营本扩展的用户账号系统，也不通过本扩展建立用户个人资料库。当前版本不包含广告 SDK 或行为分析 SDK。

当前版本不会将用户的书签列表、密码、表单内容或网页截图发送给开发者服务器。书签展示、设置保存、点击统计和截图生成主要在用户设备本地完成。

但为实现天气、IP 定位、节假日、汇率、热点、每日壁纸、模型目录及网站图标等功能，扩展会按上述说明向相应第三方服务发送请求。网络服务提供方可能处理请求所必需的 IP 地址、请求时间、请求参数或网站域名等信息。请参阅相应服务提供方的隐私政策。

4. 权限用途

  • storage：在本地保存扩展设置、偏好和缓存。
  • bookmarks：读取并展示书签；在用户主动操作时执行书签管理操作。
  • tabs（可选）：在用户使用截图或相关标签页功能时读取当前窗口标签页信息。
  • scripting（可选）：在用户选择网页截图目标后，执行必要的页面截图脚本。
  • 网站访问权限（按需申请）：用于用户选择的网站截图或用户启用的图标自动缓存等功能。部分功能可能需要访问相应网站以获取图标或页面信息。

用户可以在 Microsoft Edge 的扩展管理或网站权限设置中查看、管理或撤销相关权限。撤销权限后，依赖该权限的功能可能无法正常使用。

5. 数据保存与安全

扩展设置、缓存、壁纸及相关本地信息保存在用户设备的浏览器本地存储中。开发者不通过本扩展维护云端用户数据账户。

开发者会尽合理努力减少不必要的数据访问，并通过 HTTPS 访问扩展声明的固定网络服务。但互联网传输和第三方服务均存在其自身的安全及隐私风险；第三方服务的数据保存期限和安全措施由其运营者决定。

6. 用户可以如何管理信息

用户可以：

  1. 在扩展设置中关闭天气、图标自动缓存等非必要功能；
  2. 拒绝或撤销浏览器的定位权限；
  3. 在 Edge 扩展管理页面撤销扩展权限；
  4. 删除扩展本地数据，或卸载扩展；
  5. 不填写或停用自定义 AI 数据更新源。

删除扩展数据或卸载扩展前，请先导出或备份希望保留的书签、壁纸或设置。浏览器本地数据删除后，开发者无法替用户恢复。

7. 儿童隐私

本扩展不是专门面向儿童设计的服务。若监护人认为儿童在使用过程中向第三方服务提供了不适当的个人信息，请通过本政策所列邮箱联系开发者。

8. 政策更新

当扩展功能、权限或数据处理方式发生变化时，开发者可能更新本政策。更新后的版本会发布在本政策页面，并更新生效日期。建议用户不时查看本页面。
